# 🧪 COVID-19 Clinical Trials Data Analysis

## 📌 Project Overview
An end-to-end healthcare analytics project analyzing global COVID-19 clinical trial activity across **5,783 trial records** (27 attributes) sourced from ClinicalTrials.gov. The goal was to uncover how the global research community responded to the pandemic — trial status, study design choices, enrollment scale, and activity trends — and deliver an interactive Power BI dashboard for stakeholder reporting.

## 🎯 Objectives
- 📊 Analyze clinical trial trends across 5,783 cleaned trial records.
- 🔬 Compare study design types and identify the most-studied conditions.
- ⏱️ Understand trial duration patterns and pandemic-period activity spikes.
- 📈 Deliver an interactive dashboard for trial monitoring and reporting.

## 🛠️ Tools Used
- 🐍 **Python** — Pandas, Matplotlib, Seaborn (EDA & data cleaning)
- 🗄️ **MySQL** — Data storage and querying
- 📊 **Power BI** — Dashboard development
- 📗 **MS Excel** — Supplementary data checks and formatting

## 📂 Dataset
- **COVID-19 Clinical Trials Dataset** (ClinicalTrials.gov)
- Raw dataset cleaned and preprocessed to **5,783 records** across **27 columns** (missing values handled, dates standardized, duration & enrollment features engineered)

## 🔄 Project Workflow
1. 🧹 Data Cleaning (Python — handling nulls, date parsing, standardizing categorical fields)
2. 🧮 Feature Engineering (Trial Duration, Enrollment Category, Start Month)
3. 🔍 Exploratory Data Analysis (EDA)
4. ✅ Data Validation (MySQL queries for consistency checks)
5. 📊 KPI Creation & Dashboard Development (Power BI)
6. 💡 Business Insights & Recommendations

## 🖥️ Dashboard Features
- 🟦 KPI Cards (Total Trials, Study Type Split, Median Duration)
- 🔁 Trial Status Trend Analysis
- 🧬 Top Conditions & Trial Phases Breakdown
- 📅 Trials Started by Month (Timeline View)
- 🏥 Enrollment Category Comparison
- 🎛️ Interactive Slicers (Status, Phase, Study Type)

## 💡 Key Business Insights
- ✅ Most clinical trials reached completion successfully.
- 📈 Trial activity spiked sharply during the early pandemic months (Mar–Jun 2020).
- 🏥 Medium-sized enrollment trials were the most common category.
- 🌍 Majority of studies ran across multiple global locations.
- 🔬 Phase 3 trials were disproportionately frequent, reflecting urgency to validate treatments/vaccines at scale.
- ⚠️ A notable share of trials never published public results — a reporting gap worth flagging.
- 📊 Dashboard enables stakeholders to monitor global trial activity and study design trends in real time.
